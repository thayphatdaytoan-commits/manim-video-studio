# Thư mục `scenes/` — code Manim do Cursor Agent viết

**Hướng A (khuyến nghị):** Giáo viên nhờ **Cursor Agent** viết/sửa file `.py` tại đây, rồi copy vào editor trên Manim Video Studio (cột 3) để Validate và biên dịch video.

## Quy trình nhanh

1. Studio cột 1–2: nhập đề, lời giải, GeoGebra, lưu hình.
2. Studio cột 3: **Copy brief cho Cursor Agent** → dán vào chat Cursor.
3. Cursor: tạo/sửa `scenes/TenBai.py`.
4. Copy nội dung file → dán vào editor Studio → **Validate CE** → **Biên dịch**.

## Đặt tên file

- `HinhHoc_AHCK.py`, `PhuongTrinh_Bac2.py`, …
- Tên class Scene trùng với tên chọn trên Studio (hoặc đổi dropdown Scene sau khi dán code).
