Luồng TQH (hình học, Venn, đồ thị đều dùng):
  1) problem_and_figure: đề TRÊN (center_x) → hình DƯỚI (fit_figure_full_width + center_x)
  2) transition: FadeOut(problem_block) → fit_figure_full_width(FIGURE_RATIO) → to_edge(UP, buff=TOP_BUFF) → center_x(figure)
  3) solution_steps: 1 dòng/beat, next_to(figure, DOWN, buff=0.08) → center_x; font 28–32
  4) page_break: sau 4 dòng → FadeOut(solution_stack), GIỮ figure

=== KÝ HIỆU GÓC — LUÔN < 180° (CẤM cung reflex quanh đỉnh) ===
Hàm bắt buộc khi vẽ góc:
  def interior_angle_at(vertex, arm1, arm2, radius=0.28, color=None, **kwargs):
      v = vertex.get_center(); a1 = arm1.get_center(); a2 = arm2.get_center()
      return Angle(Line(v,a1,buff=0), Line(v,a2,buff=0), radius=radius, other_angle=False, color=color or "#FFD700", **kwargs)
  def right_angle_at(vertex, arm1, arm2, length=0.22, **kwargs):
      v = vertex.get_center(); a1 = arm1.get_center(); a2 = arm2.get_center()
      return RightAngle(Line(v,a1,buff=0), Line(v,a2,buff=0), length=length, **kwargs)

Quy tắc:
  - ∠ABC tại B → interior_angle_at(B, A, C) — 2 tia XUẤT PHÁT TỪ đỉnh B
  - Góc vuông → right_angle_at(đỉnh, arm1, arm2)
  - CẤM: Angle(Line(A,B), Line(B,C)) nếu không chắc chiều tia từ đỉnh
  - CẤM: Arc(angle>PI), other_angle=True, cung vàng gần full vòng
  - Nếu vẫn sai: đổi thứ tự arm1/arm2
